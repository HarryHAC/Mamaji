# Mama Ji

Voice-powered local grocery shopping for Nepali, Maithili, Bhojpuri, and English users.

## Live Demo

**[Open Mama Ji](https://apna-kirana-sand.vercel.app)**

This is a test version. Please do not use real payments or sensitive personal information.

## Run Locally

```bash
npm install
npm run dev
```

Create a production build with:

```bash
npm run build
```

## Current Scope

- Customer and shopkeeper demo flows
- Product search and cart
- Delivery and pickup checkout
- Voice shopping interface
- Nepali, Maithili, Bhojpuri, and English UI

The current demo stores accounts and orders in browser local storage. It is intended for usability testing, not production payments or sensitive data.
